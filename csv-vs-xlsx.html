CSV vs XLSX: which format should you use?

CSV and XLSX both store tables, but they solve different problems. Use this page to pick the right one.

FeatureCSVXLSX
What it isPlain text, one row per line, values split by a separatorA zipped package of XML files used by Excel
FormattingNone. No bold, colors or column widthsFonts, colors, widths, frozen rows and filters
FormulasValues onlyFormulas and calculated cells
Multiple sheetsOne table per fileMany sheets in one workbook
Charts and imagesNot supportedSupported
Data typesEverything is text until a program guessesText, numbers and dates are stored explicitly
File sizeSmall for simple dataCompressed, but can be larger for tiny tables
Best forMoving data between systems, imports, exports, scriptsReading, analyzing and sharing data with people

When to use CSV

Choose CSV when software needs to read the data: importing contacts into a CRM, loading products into a store, or feeding a database or script. CSV is universal and lightweight.

When to use XLSX

Choose XLSX when a person will work with the data. You get readable columns, a styled header, filters and a frozen top row, and you can add formulas or more sheets later.
