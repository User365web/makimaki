How to convert CSV to Excel

You can turn a CSV file into an Excel workbook in three ways. This guide covers each one, plus fixes for the problems people hit most often.

Method 1: Use makiconvertpro

  1. Open the converter and drop your CSV file on the grid.
  2. Check the preview of the first rows.
  3. Select Download Excel file.

This is the quickest option for one-off files, and your data never leaves your device.

Method 2: Import the file in Excel

  1. Open a blank workbook in Excel.
  2. Go to the Data tab and choose From Text/CSV.
  3. Select your file, check the delimiter and encoding in the preview, then select Load.
  4. Save the workbook as .xlsx.

Method 3: Open and save as .xlsx

  1. Double-click the CSV so it opens in Excel.
  2. Choose File, then Save As.
  3. Pick Excel Workbook (*.xlsx) and save.

This route is simple but lets Excel guess data types, which is how leading zeros and long numbers get damaged.

Fix common CSV to Excel problems

All data lands in one column

The file uses a separator your computer does not expect, often a semicolon. Set the separator by hand in the converter, or use From Text/CSV in Excel and choose the delimiter.

Accents and symbols look garbled

The file encoding does not match. Export the CSV again as UTF-8 from the source program, or convert it with makiconvertpro, which reads UTF-8, UTF-16 and Windows-1252.

Leading zeros disappear

Excel treats 00123 as the number 123 when it opens a CSV directly. Converting with makiconvertpro keeps these values as text.

Long numbers turn into scientific notation

Excel shows numbers longer than 15 digits as 1.23E+15 and rounds the extra digits. makiconvertpro only converts numbers up to 15 digits and stores longer ones, such as card or tracking numbers, as text.

Dates look wrong

Day-first and month-first formats are ambiguous. makiconvertpro keeps dates exactly as written in the CSV, so you can apply the date format you need in Excel afterwards.
